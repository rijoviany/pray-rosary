## 4. How to Generate in Nano Banana

1. **Step 1: Anchor the First Image**
   Generate `mystery_joyful_1.png` first using the Annunciation prompt. Once you have Mary’s face and robe colors looking authentic, use that image as your **image reference** input for all subsequent prompts where Mary appears.

2. **Step 2: Anchor Jesus**
   Generate `mystery_luminous_1.png` (Baptism) or `mystery_glorious_1.png` (Resurrection) to lock in Jesus’s facial features and cruciform halo. Use that output as the character reference for all subsequent Christ depictions.

3. **Step 3: Save Assets to the Android App**
   Save the 20 generated square (1:1) PNG images directly into your app’s drawable folder:
   ```
   app/src/main/res/drawable-nodpi/
   ├── mystery_joyful_1.png
   ├── mystery_joyful_2.png
   ├── mystery_joyful_3.png
   ├── mystery_joyful_4.png

   ├── mystery_luminous_4.png
   ├── mystery_luminous_5.png
   ├── mystery_sorrowful_1.png
   ├── mystery_sorrowful_2.png
   ├── mystery_sorrowful_3.png
   ├── mystery_sorrowful_4.png

   ```
